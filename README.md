# Weave

**Weave** is a locally hosted version control system developed in C++ as part of my third-year university Production Project. Inspired by [Mercurial](https://www.mercurial-scm.org/), it explores revision tracking, repository management and efficient storage through a command-line interface.

The project adopts Mercurial's revlog-based storage approach, providing a foundation for tracking file revisions and managing repository history.

## Development

Developed as a third-year Production Project, Weave provided an opportunity to explore version control system internals, storage architectures, and systems programming in C++.

## Technologies

- **Language:** C++
- **Architecture:** Mercurial-inspired revlog storage
- **Interface:** Command-line
- **Build system:** CMake

## Successor Project

Weave2 is the successor to this project, taking a different architectural approach inspired by Git. It expands on the original concept with a focus on branching, repository management and asynchronous processing.
